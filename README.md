# 🇮🇳 Indian Visa Autofill Cloud

A Cloud-synced Chrome Extension that extracts data from Passport PDFs/Images and instantly autofills the Indian Visa Application form. All profiles and settings are synced via a secure backend API.

## ✨ Features
- **Cloud Sync:** Keeps all your profiles synced securely.
- **Multi-Visa Support:** Full support for Tourism, Medical, and Business Visa autofill.
- **Smart Widget:** A floating widget directly on the visa website allows you to quickly select profiles and fill forms page-by-page.
- **Document Generator:** Instantly generate printable Cover Letters, NOCs, Medical Undertakings, and Photo Attachment Forms with one click.
- **Digital Photo Attachment:** Upload your passport photo and automatically paste it onto generated documents.
- **Dark/Light Mode:** Beautiful, responsive UI with state-of-the-art glassmorphism design.

---

## 📖 User Guide (English)

### Installation
1. Download or clone this repository.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top right corner).
4. Click **Load unpacked** and select the `Indian Visa Autofill Cloud` folder.

### How to Use
1. **Add a Profile:** Click the extension icon. Your data will be saved and synced to the cloud server.
2. **Edit Profile:** Upload your passport photo and fill in missing fields (like address or parents' info).
3. **Autofill:** Go to the Indian Visa application website. A floating widget will appear. Select your profile and let it autofill the pages!
4. **Generate Documents:** In the extension popup, use the "Generate Documents" section to instantly print Cover Letters or Photo Forms.

### ইন্সটলেশন (Installation)
১. এই রিপোজিটরি থেকে প্রজেক্টটি ডাউনলোড করুন।

৩. ডানপাশের উপরের কোণায় থাকা **Developer mode** অন করুন।
৪. **Load unpacked** বাটনে ক্লিক করে `Indian Visa Autofill Cloud` ফোল্ডারটি সিলেক্ট করুন।

### কীভাবে ব্যবহার করবেন?
১. **প্রোফাইল তৈরি:** এক্সটেনশন আইকনে ক্লিক করে নতুন প্রোফাইল তৈরি করুন। আপনার সব ডেটা ক্লাউড সার্ভারে সেভ হবে। 
২. **প্রোফাইল এডিট:** এডিট অপশনে গিয়ে আপনার ছবি (Passport Photo) আপলোড করুন এবং বাকি প্রয়োজনীয় তথ্যগুলো (যেমন ঠিকানা) পূরণ করে সেভ করুন।
৩. **অটোফিল (Autofill):** ইন্ডিয়ান ভিসার ওয়েবসাইটে প্রবেশ করুন। সেখানে ভাসমান (Floating) উইজেট দেখতে পাবেন। আপনার প্রোফাইল সিলেক্ট করে ফর্ম পূরণের কাজ শুরু করুন।
৪. **ডকুমেন্ট তৈরি:** এক্সটেনশনের ভেতরে "Generate Documents" সেকশন থেকে মাত্র এক ক্লিকেই Cover Letter, NOC বা Photo Form তৈরি করে প্রিন্ট করতে পারবেন।
